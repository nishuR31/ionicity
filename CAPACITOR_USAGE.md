# Capacitor usage & where to write the web app

## Summary

- Write and edit your web app in the `src/` folder (HTML, JS, CSS).
- Vite builds the production web assets into `dist/` (configured in `vite.config.ts`).
- Run `cap sync` (or `bunx cap sync android`) to copy `dist/` into the native Android app at `android/app/src/main/assets/public`.

## Files to edit

- `src/index.html` — app entry HTML. Keep a single `<div id="app">` as the mount point.
- `src/main.js` — app entry module (imports your components and `app.js`).
- `src/app.js` — primary UI rendering and boot logic (current single-file app). Split into modules under `src/js/` when you want modular structure.
- `src/js/components/` — place reusable UI components here.

## Build & package steps (quick)

1. Build web assets:

```bash
bun run build
```

2. Sync web assets into native projects (copies `dist/` to Android assets):

```bash
bunx cap sync android
```

3. Build Android debug APK:

```bash
cd android
./gradlew assembleDebug --no-daemon
```

## Notes

- Only files inside `src/` affect the web app you edit. Do not edit files under `android/app/src/main/assets/public` — they are generated by the build + `cap sync` step and will be overwritten.
- If you see the Capacitor "welcome" content at runtime, check `src/` for any `capacitor-welcome` component or files that auto-register it. Remove or rename those files if you don't want the welcome UI.
- The app UI is rendered into the element with `id="app"`; ensure your main module (`src/main.js` / `src/app.js`) writes your UI there.
